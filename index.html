OPTICS / 01

PyMieSim

↗

Light scattering, made explorable.

A Python interface to Lorenz–Mie scattering, backed by C++ for single-particle studies and parameter sweeps.

Python · C++ · pybind11

Inside the project +
The question

Model how particle size, material, illumination, and detector geometry influence a scattering measurement.

The implementation

Solvers for spheres, cylinders, and core–shell particles connect configurable sources and detectors to pandas outputs.

Why it matters

Brings the physical model and experimental configuration into one reproducible workflow.

MEASUREMENT / 02

FlowCyPy

↗

From particles to detector signals.

Simulating flow cytometry experiments through particle populations, optical scattering, and realistic detector response.

Python · Simulation · Signal processing

Inside the project +
The question

Understand how a particle population becomes a measured time trace, including the effects of noise and instrument settings.

The implementation

Combines particle events, forward and side scattering, fluorescence, detector saturation, and thermal, shot, and dark-current noise.

Why it matters

Makes it possible to explore experimental conditions and evaluate analysis on simulated signals.

Explore the source & documentation ↗
OPTICS / 03

LightWave2D

↗

Watch electromagnetic fields evolve.

Two-dimensional FDTD simulations for wave propagation, diffraction, and optical components.

Python · C++ · FDTD

Inside the project +
The question

Explore how electromagnetic waves interact with an optical geometry.

The implementation

A configurable simulation API supports waveguides, scatterers, gratings, and resonators, with field animation tools.

Why it matters

Turns a numerical field calculation into a visual workflow for studying optical designs.

OPTICS / 04

PackLab

↗

Structure changes the scattering story.

Analytical and numerical tools for structure in three-dimensional hard-sphere systems.

Python · Monte Carlo · Statistical physics

Inside the project +
The question

Distinguish equilibrium structure from the configurations produced by irreversible particle deposition.

The implementation

Combines a Percus–Yevick equilibrium reference, random sequential adsorption, and fixed-volume Metropolis Monte Carlo sampling.

Why it matters

Connects particle structure to pair correlations, structure factors, and optional PyMieSim scattering calculations.

Explore the source & documentation ↗
MEASUREMENT / 05

RosettaX

↗

Calibration you can inspect and reuse.

An interactive application connecting cytometry data, optical models, and calibration references.

Python · GUI · Calibration

Inside the project +
The question

Make calibration repeatable when instrument data, peak selection, fits, and exported settings would otherwise live in separate tools.

The implementation

Brings FCS loading, histogram inspection, peak identification, fluorescence and scattering fits, and profile management into a local graphical workflow.

Why it matters

Keeps calibration choices inspectable and exports reusable results for downstream analysis.

Explore the source & documentation ↗
SIGNALS / 06

DeepPeak

↗

Finding events in noisy signals.

Classical peak detection and optional neural deconvolution for sparse, one-dimensional measurements.

Python · Neural networks · Signal analysis

Inside the project +
The question

Evaluate event detection when noise and overlapping pulses complicate time-series analysis.

The implementation

Provides synthetic signals, classical detectors, CNN, WaveNet, and 1D U-Net models, plus direct-versus-deconvolved evaluation.

Why it matters

Compares counts, arrival times, amplitudes, and widths on the same traces, including dilution-series workflows.
