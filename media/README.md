# Portfolio visuals

The website is self-contained. Project SVG illustrations are embedded in `index.html`; the interactive wave illustration is drawn by `assets/main.js`. The icon lives in `assets/favicon.svg`.

These are original schematic illustrations, not outputs from the featured simulation packages. The wave control uses arbitrary units.

For future screenshots or scientific figures, include the project version, generating example, and relevant physical parameters. Optimize files before adding them to `assets/` and provide descriptive alternative text.
