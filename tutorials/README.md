# Learn from the projects

The maintained examples and documentation live alongside their respective projects:

- [PyMieSim](https://github.com/MartinPdeS/PyMieSim): scattering studies and parameter sweeps.
- [LightWave2D](https://github.com/MartinPdeS/LightWave2D): wave propagation and field animation.
- [FlowCyPy](https://github.com/MartinPdeS/FlowCyPy): simulated cytometry experiments.
- [DeepPeak](https://github.com/MartinPdeS/DeepPeak): signal generation and peak analysis.
- [PackLab](https://github.com/MartinPdeS/PackLab): analytical structure and particle configurations.

Start with each repository’s README for installation and documentation links. Match examples to the version you install.
